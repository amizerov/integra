Назначение

Хранимая процедура dbo.am_GetEducPlans предназначена для получения списка учебных планов факультета, которые реально используются в заданном учебном году и имеют учебную нагрузку в указанном терме.

Где применяется

  • визарде создания расписания,
  • RAG-агентах для SQL reasoning,
  • построении дерева «Факультет → План → Курс → Предмет».

Сигнатура процедуры

dbo.am_GetEducPlans
(
    @Nfirm        INT,      -- факультет (Firm.Nfirm)
    @Year_Study   INT,      -- год начала учебного года (например, 2025 для 2025/26)
    @Num_Term     INT = 1,  -- сквозной номер терма (1..12, иногда 13)
    @Fk_Form_Educ INT = 0,  -- форма обучения (0 = не фильтровать)
    @Fk_Type      INT = 0   -- тип обучения (0 = не фильтровать)
)

Логика работы

1) Определение курса по терму

Формула:

  • Course = ((Num_Term - 1) / 2) + 1

Подсказка по диапазонам:

  • 1 курс Num_Term = 1–2
  • 2 курс Num_Term = 3–4
  • 3 курс Num_Term = 5–6
  • 4 курс Num_Term = 7–8
  • 5 курс Num_Term = 9–10
  • 6 курс Num_Term = 11–12

2) Вычисление года набора (Year_Enter)

Формула:

  • Year_Enter = Year_Study - (Course - 1)

Пример: учебный год 2025/26, Num_Term = 3 → 2 курс → Year_Enter = 2024.

3) Фильтрация по реальному набору

Используется таблица Plan_Year_Enter, что гарантирует:

  • план реально запускался,
  • студенты существуют.

4) Проверка наличия дисциплин в терме

Через EXISTS по связке Subject_Name_Order + Comp_Term отсекаются планы, у которых в указанном терме отсутствует учебная нагрузка.

Полный текст процедуры

ALTER PROC [dbo].[am_GetEducPlans]
    @Nfirm        INT,
    @Year_Study   INT,
    @Num_Term     INT = 1,
    @Fk_Form_Educ INT = 0,
    @Fk_Type      INT = 0
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @Course INT = ((@Num_Term - 1) / 2) + 1;
    DECLARE @Year_Enter INT = @Year_Study - (@Course - 1);

    SELECT DISTINCT
        ep.PrK_Plan        AS Plan_ID,
        ep.Name_Plan       AS Plan_Name,
        ep.Nfirm,
        ep.Fk_Type,
        tb.Name_Type       AS Type_Name,
        ep.Fk_Form_Educ,
        fe.Name_Form_Educ  AS Form_Name,
        ep.God,
        ep.Engl_Name_Plan  AS Engl_Plan,
        @Course            AS Course,
        @Year_Enter        AS Year_Enter
    FROM dbo.Educ_Plan ep
    JOIN dbo.Plan_Year_Enter pye
      ON pye.FK_Plan    = ep.PrK_Plan
     AND pye.Nfirm      = ep.Nfirm
     AND pye.Year_Enter = @Year_Enter
    JOIN dbo.Type_Business tb
      ON tb.PrK_Type = ep.Fk_Type
    JOIN dbo.Form_Education fe
      ON fe.PrK_Form_Educ = ep.Fk_Form_Educ
    WHERE ep.Nfirm = @Nfirm
      AND (@Fk_Form_Educ = 0 OR ep.Fk_Form_Educ = @Fk_Form_Educ)
      AND (@Fk_Type = 0 OR ep.Fk_Type = @Fk_Type)
      AND EXISTS (
          SELECT 1
          FROM dbo.Subject_Name_Order sno
          JOIN dbo.Comp_Term ct
            ON ct.NFirm      = sno.NFirm
           AND ct.CodOrderID = sno.PrK_Subject_Order
          WHERE sno.FK_Plan = ep.PrK_Plan
            AND sno.NFirm  = ep.Nfirm
            AND ct.Num_Term = @Num_Term
            AND ct.Beg_Act <= @Year_Enter
            AND (ct.End_Act = 0 OR ct.End_Act >= @Year_Enter)
      )
    ORDER BY ep.Name_Plan;
END

Ключевые выводы для RAG

  • Num_Term — главный управляющий параметр.
  • Курс и год набора вычисляются автоматически.
  • Возвращаются только планы, для которых реально можно строить расписание.
  • Корректная точка входа для визарда расписания и RAG-агентов.
